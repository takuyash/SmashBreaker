# 家具ナゲール

家電をぶん投げて壊しまくる、ブラウザで遊べるストレス発散ゲームです。
PC でもスマホでも遊べます。

▶ **プレイする:** https://takuyash.github.io/SmashBreaker/index.html

## 遊び方

パワーを溜めて家電を投げ、壊した金額を積み上げましょう。
ストレスゲージが 0% になるとクリアです。

- **パワー:** 約 0.9 秒で最大まで溜まります。溜めている間は飛ぶ軌道が点線で表示されます。
- **ダメージ:** 家電にはそれぞれ耐久値があり、強く当てるほど大きなダメージになります。与えたダメージに応じて「破壊総額」が増え、ストレスが減ります。
- **破損:** 当たるたびに凹んだり、部品が外れたりします。耐久値が 0 になると粉々に砕けます。
- **壁のひび:** 強く当てると、壁や床にひびが入ります（「片付け」で元に戻ります）。
- **ど真ん中ボーナス:** 正面の壁の的に勢いよく命中させると「ど真ん中!!」と表示され、ストレスが余分に減ります。
- **コンボ:** 2.5 秒以内に続けて壊すとコンボになり、ストレスがさらに減ります。
- **スローモーション:** 猛スピードで叩きつけて壊すと、一瞬スローになります。

| 投げる物 | 壊したときの演出 |
| --- | --- |
| 電子レンジ / ノートPC / トースター / 扇風機 | 火花・放電 |
| 電気ケトル | 水が飛び散る |
| 炊飯器 | ご飯粒が飛び散る |
| プリンター | インクと紙が舞う |
| ブラウン管TV | 画面のガラスが砕け散る |
| マグカップ | 破片とコーヒーが飛び散る |

家電はどれも火花や放電を出します（上の表は、それに加えて出る演出です）。

### PC

| 操作 | 内容 |
| --- | --- |
| マウス長押し | パワーを溜める |
| 離す | カーソルの位置へ投げる |
| `1`〜`9` | 投げる物を切り替え |
| `0` | ランダム |
| `Space` | 長押しで溜めて、離して投げる |
| `C` | 片付け |
| `M` | 音の ON / OFF |

### スマホ

| 操作 | 内容 |
| --- | --- |
| 画面を長押し | パワーを溜める |
| 指をなぞる | 狙いを調整 |
| 指を離す | その位置へ投げる |
| 下のアイコン | 投げる物を切り替え（横スクロール） |
| 🧹 / 🔊 ボタン | 片付け / 音の ON / OFF |

縦持ち・横持ちのどちらでも遊べます。

## 技術的な特徴

外部の JavaScript ライブラリは使わず、ブラウザの標準機能だけで作っています。
外部から読み込んでいるのは、Google Fonts のフォント「Dela Gothic One」だけです。

### 3D 描画（CSS 3D Transforms）

- WebGL は使わず、`div` の面を `matrix3d` と `preserve-3d` で 3D 空間に並べて描いています。
- 家電は箱・板・円柱などの部品を組み合わせて作っています。
- 光の当たり方は、面の向きから明るさを計算して表現しています。
- ベクトル・クォータニオン・行列の計算も自作です。
- 部屋の大きさは、幅 8m × 奥行き 10m × 高さ 5m です。

### 物理演算（自前の簡易剛体）

- 重力・速度・回転を計算し、1 フレームを 3 回に分けて処理しています。
- 当たり判定は、物体を囲む箱の 8 つの角と、部屋の面（床・壁・天井）との間だけで行います。**物体どうしはぶつからず、すり抜けます。**
- ぶつかったときは、跳ね返り（素材ごとに強さが違います）と摩擦を計算しています。
- 止まった物体は計算を止めて負荷を減らしています。物体の数は最大 170 個までで、超えると小さな破片から消えます。
- 狙いは、カーソルの方向にある部屋の面との交点で決め、そこに届く放物線を計算して投げています。

### エフェクト（Canvas 2D）

- 粉じん・液体の粒・火花をパーティクルとして描いています。3D 描画と同じカメラで位置を計算しているので、ずれずに重なります。
- 壁や床のひびは、Canvas に直接描き込んでいます。

### サウンド（Web Audio API）

- 音声ファイルは使わず、ノイズと発振器を組み合わせてその場で音を作っています。
- 金属・プラスチック・ガラス・陶器などで鳴り分けます。左右の位置に応じて音が聞こえる方向も変わります。

### テクスチャ

- ノートPC やブラウン管の画面、キーボード、壁、床は、すべて Canvas で描いて作っています（画像ファイルは使っていません）。

## ローカルで動かす

ビルドは不要です。リポジトリをクローンして `index.html` をブラウザで開けば遊べます。

```
index.html   画面の構成
main.js      ゲーム本体
style.css    スタイル
```
