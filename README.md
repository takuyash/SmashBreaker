# SMASH BREAKER

家電をぶん投げて壊しまくる、ブラウザで遊べるストレス発散ゲームです。
PC でもスマホでも遊べます。

▶ **プレイする:** https://takuyash.github.io/SmashBreaker/index.html

## 遊び方

パワーを溜めて家電を投げ、壊した金額を積み上げましょう。
ストレスゲージが 0% になるとクリアです。連続で壊すとコンボになります。

### PC

| 操作 | 内容 |
| --- | --- |
| マウス長押し | パワーを溜める |
| 離す | カーソルの位置へ投げる |
| `1`〜`9` | 投げる物を切り替え |
| `0` | ランダム |
| `Space` | 長押しで溜めて、離して投げる |
| `C` | 片付け |
| `M` | 音の ON / OFF |

### スマホ

| 操作 | 内容 |
| --- | --- |
| 画面を長押し | パワーを溜める |
| 指をなぞる | 狙いを調整 |
| 指を離す | その位置へ投げる |
| 下のアイコン | 投げる物を切り替え（横スクロール） |
| 🧹 / 🔊 ボタン | 片付け / 音の ON / OFF |

縦持ち・横持ちのどちらでも遊べます。

## 投げられる物

電子レンジ / 電気ケトル / 炊飯器 / ノートPC / ブラウン管TV / トースター / プリンター / 扇風機 / マグカップ

## 技術的な特徴

外部の JavaScript ライブラリは使わず、ブラウザの標準機能だけで作っています。

- **3D 描画:** CSS 3D Transforms
- **エフェクト:** Canvas 2D
- **サウンド:** Web Audio API（音声ファイルは使わず、その場で音を作っています）
- **テクスチャ:** Canvas で描いて生成（画像ファイルは使っていません）
- **物理演算:** 自前で実装

外部から読み込んでいるのは、Google Fonts のフォント「Dela Gothic One」だけです。

## ローカルで動かす

ビルドは不要です。リポジトリをクローンして `index.html` をブラウザで開けば遊べます。

```
index.html   画面の構成
main.js      ゲーム本体
style.css    スタイル
```
